# MiJuego

Tu juego vive aquí.

## Estructura sugerida

```
MiJuego/
├─ Escenas/       MiNivel.unity, MiJefe.unity
├─ Scripts/       tus scripts propios
├─ Arte/          tus sprites (PPU 32, pivote abajo-centro)
├─ Animaciones/   clips y controllers propios
└─ Audio/         SFX y música
```

## Flujo sugerido

1. **Semana 1:** escena vacía con tu personaje.
2. **Semana 2:** movimiento y salto ajustados.
3. **Semana 3:** disparo y un enemigo.
4. **Semana 4:** nivel con cámara y meta.
5. **Semana 5:** jefe y pantalla final.

## Checklist antes de entregar

- [ ] El nivel se puede terminar.
- [ ] La cámara no muestra el vacío.
- [ ] El HUD refleja la vida real.
- [ ] La pausa funciona.
- [ ] Hay pantalla de victoria y de derrota.
- [ ] Todos los sprites son propios o están acreditados.
- [ ] El build corre fuera de Unity.

> No borres los placeholders del proyecto base: si los necesitas de referencia, están en `Assets/_SlugLab/Art/`.
