# Entregas

Aquí van tus **reportes de laboratorio**, uno por módulo.

1. Copia `plantillas/reporte-pruebas.md`.
2. Renómbralo `M03-apellido.md` (o `M03-nombre.md`).
3. Complétalo con los resultados y una captura o GIF por caso.
4. Commit y push.

Ejemplo:

```
entregas/
├─ M01-garcia.md
├─ M03-garcia.md
└─ final-garcia.md
```

## Qué NO va aquí

- **Builds** (`.exe`, `.apk`, WebGL): se suben a itch.io o a Google Drive. El enlace va en el README de tu repositorio.
- **Assets** (sprites, audio): van en `Assets/_Curso/MiJuego/`.
- **Escenas**: van en `Assets/_Curso/MiJuego/Escenas/`.
